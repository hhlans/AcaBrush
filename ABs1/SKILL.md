# AcaBrush · ABs1 绘图规范

**本 skill 是主要规范，附带代码及示例只供参考。** 不依赖特定本机目录、环境名称、工程结构或其他 skill。优先复用用户已有的绘图函数；可按本规范实现或调整代码，无需照搬参考工程。

## 全局样式

| 项目 | 固定值 |
|---|---|
| 字体 | Arial → Helvetica → DejaVu Sans |
| 正文、坐标轴标签、刻度、图例 | 16 pt |
| 子图编号 | a、b、c…，22 pt，加粗，按从左到右、从上到下排序 |
| 坐标轴、刻度线、数据线、误差线、参考线 | 1.2 pt |
| 主刻度长度 | 5 pt，向外 |
| 点型大小、边缘宽 | 4 pt、1.2 pt |
| 网格 | 默认关闭；启用时 0.6 pt |
| 默认外观 | 白底，无上/右轴框，默认无标题 |

编号在布局完成后按完整子图边界（含轴标签、刻度文字）的左缘对齐，置于绘图区上沿外侧，留少量间隔。不得遮挡文字、图例或数据。

## 图幅：固定基础尺寸、整数倍占格

- 固定基础单元为 **3×2.8 inch（宽×高）**，包含轴标签、刻度、编号和留白，不是内部数据绘图区。
- 宽、高只能各取正整数个单元：1×1 为 3×2.8，2×1 为 6×2.8，1×2 为 3×5.6，2×2 为 6×5.6 inch。
- 标签、图例、注释、曲线或矩阵内容拥挤时，只增加需要放大的子图的占格。普通子图保持原占格，不随邻图拉伸。
- **总宽 = 占格列数×3，总高 = 占格行数×2.8 inch。** 改变局部占格后重新布局并计算总画布，不在固定总图幅里压缩其他子图来腾位置。图例和留白也应明确占格。
- **图幅放大后，字体、字号、各类线宽、刻度长度、点大小、图例及编号字号均保持固定。** 不使用任意尺寸、非整数倍、缩小字体或整体缩放成图来解决拥挤；按实际图幅导出，不紧裁改变尺寸。

例如：`a a b` 表示 a 占两格、b 占一格，总图幅自动为 9×2.8 inch。复杂组图可用：

```text
a a b c
a a d d
e e f f
e e 图例 图例
```

该布局为 4×4 格，总幅 12×11.2 inch；a/e 为 6×5.6，b/c 为 3×2.8，d/f 为 6×2.8 inch。实现方式不限，参考代码中的占格接口不是使用本 skill 的前提。

## 配色和点型

标准色按色系分批，**同一个 ax 内依次选取；新 ax 或清空后都从头开始**。同一数据组跨面板应保持颜色与点型一致。

| 顺序 | 色系 | HEX |
|---|---|---|
| 1–2 | 蓝色 | `#96C2D6`、`#13A4BD` |
| 3–4 | 绿色 | `#81BFAD`、`#3E8043` |
| 5–8 | 暖黄橙棕 | `#E6DD96`、`#F4BA6E`、`#E2977C`、`#C7A48E` |
| 9–12 | 粉紫 | `#EAAEBC`、`#D87F98`、`#C5AFD1`、`#B9719E` |

点型顺序：方形、上三角、菱形、下三角、加号形、叉形、左三角、右三角、六边形、星形、细菱形、圆形；**圆形最后**。纯线、填充边界和误差线端帽不推进点型序号。每组只计一次，不因多个图元额外跳色；同一组的线、点和区间带复用颜色。柱状图每根柱、小提琴图每组分布依次取色。

蓝粉热力图融合全部六个锚点：

`#13A4BD → #96C2D6 → #C5AFD1 → #EAAEBC → #D87F98 → #B9719E`

六色都参与连续插值，不仅使用两个端点。可比热力图统一数值范围；分类色序不直接当连续数值梯度。可选择派生暖色库或用户指定配色，仍保持库内顺序；颜色数据见 [配色库说明](../ABsCol/README.md)。

## 绘制与检查

1. 绘图函数接收已有 `ax`、数据及参数，只绘制图元与设置样式，不创建画布、不清空已有内容、不设置范围/刻度或保存。同一 ax 可反复调用不同函数，叠加多组及不同图型。
2. 调用方统一管理布局、范围、刻度、注释、图例和导出。范围覆盖全部观测、预测与不确定性；连续轴用等间距主刻度封住两端，通常约 3–4 个，先尝试约 2%–5% 边距。分类轴保留所需标签，拥挤时增加整数占格。
3. 图例放数据稀疏处，密集时使用独立占格。色条在热力图所属单元内预留空间，不挤压其他子图。实际图幅下检查文字、图例、数据与编号无遮挡。
4. 使用真实数据时保留全部观测，说明样本量、统计量及误差定义；模拟示例明确标注。比较面板检查边界、尺寸和间距对齐，建议物理容差 1.5 pt，并说明必要的局部例外。
5. 只导出 PDF 图像到运行代码旁的 `Figure/`，保持文字可编辑及规定的实际尺寸。检查导出 PDF 的字体、裁切、碰撞和可读性。检查方法不限，不依赖特定本机审查脚本；未执行的检查不得声称通过。
6. 源数据和运行记录可写入 `Log/`；分享规范或示例时排除本机绝对路径、个人信息、历史日志、缓存和临时文件。
