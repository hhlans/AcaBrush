# AcaBrush · ABs1 绘图规范

**本 skill 是主要规范，代码仅供参考。** 优先复用用户已有绘图函数；使用规范不依赖特定本机路径、环境或其他 skill。

## 全局样式

| 项目 | 固定值 |
|---|---|
| 字体 | Arial → Helvetica → DejaVu Sans |
| 正文、轴标题、刻度、图例 | 14 pt |
| 子图编号 | a、b、c…，22 pt，加粗，从左到右、从上到下 |
| 轴线、刻度线、数据线、误差线、参考线、点边缘 | 0.9 pt |
| 主刻度 | 长 5 pt，向外 |
| 点大小 | 4 pt |
| 网格 | 默认关闭；启用时 0.6 pt |
| 外观 | 白底，默认无标题；普通图隐藏上/右轴框，热力图显示四边轴框 |

字体和全部物理样式不随绘图区或总画布变化而缩放。

## 图幅与组图布局

1. **固定绘图区。** 数据绘图区指轴框内的矩形；其外围文字、图例、色条和注释属于附属占位。先确定各图绘图区宽高，已有图沿用实际尺寸。初始单图可参考 3×2.8 inch 的完整图幅。只有数据本身拥挤且调用方明确调整时，才将所需绘图区宽或高按原尺寸的正整数倍扩大；相邻图不随之拉伸，长文字不挤小绘图区。
2. **渲染后测量。** 按固定样式测量四周实际占位，包含旋转/多行刻度、伸到上方的纵轴标题、外置图例、色条及其标题。色条独立预留，不从固定绘图区扣宽。内容、换行或图例列数改变后重新测量。
3. **同行等距。** 水平真实间隙从轴内容的最外缘计算，轴内容包含数据矩形及上述附属占位，不能拿轴框间距或透明容器代替。每行连续子图的真实间隙相等，默认下限 **0.18 inch**；相邻行完整内容（含编号）之间至少 **0.20 inch**；外边距默认 **0.14 inch**。调用方可明确覆盖。
4. **按行结构对齐。** 同行绘图区上沿对齐。仅数据子图数量相同的行，按对应顺序或明确列映射建立跨行内容左缘锚点；**数量不同的行独立紧凑排布，不建立跨行列锚点**。独立图例不计入图数，也不继承其他行的列。跨列图按本行实际顺序处理，不补虚拟列。绘图区左缘对齐是独立约束，需要时显式指定，不能与内容左缘混用。
5. **编号共同排布。** 同行编号共用水平基线，位于整行最高内容上方，留统一物理间隔；同结构行对应列共用左侧锚点，其他行用本行各图的内容左缘。编号与布局一起确定，不在排完后逐个挪动。编号单独检查对齐和碰撞，不用它与轴内容的联合矩形制造虚假的水平间隙。
6. **求紧凑可行解。** 同时满足固定绘图区、样式、内容完整、无碰撞、有效对齐和同行等距，先最小化各行间隙之和，再最小化内容总宽。最小间隙模式允许必要增量，记录实际值和原因；精确模式不允许增量。约束无解或超过指定最大间隙时报告冲突，不自动改文字、字号、图例、绘图区或放弃对齐。单图内部拥挤由调用方调整换行、旋转或尺寸后再求解。
7. **总图幅不取整。** 总宽高直接由完整内容、真实间隙和指定外边距确定，不向整数、3×2.8 inch 或其他倍数补齐，不额外凑留白。画布按实际需要增减，绘图区不缩放；按该尺寸导出，不用紧裁改变指定外边距。

## 配色与点型

配色库可选，默认标准 `reference12`。**同一 ax 按顺序选取，新 ax 或清空后从头开始**；同一数据组跨面板保持颜色、点型一致。

| 顺序 | 色系 | HEX |
|---|---|---|
| 1–2 | 蓝 | `#96C2D6`、`#13A4BD` |
| 3–4 | 绿 | `#81BFAD`、`#3E8043` |
| 5–8 | 暖黄橙棕 | `#E6DD96`、`#F4BA6E`、`#E2977C`、`#C7A48E` |
| 9–12 | 粉紫 | `#EAAEBC`、`#D87F98`、`#C5AFD1`、`#B9719E` |

点型顺序：**方形、上三角、菱形、下三角、加号形、叉形、左三角、右三角、六边形、星形、细菱形、圆形**，圆形最后。每组只计一次，线、点、区间带复用该组颜色；纯线、填充边界、误差线端帽不推进点型序号。柱图每根柱、小提琴图每组分布依次取色。

蓝粉热力渐变让全部六个来源锚点参与连续插值：`#13A4BD → #96C2D6 → #C5AFD1 → #EAAEBC → #D87F98 → #B9719E`。各锚点先与白色按 25%–32% 混合提亮，保留清新色相，不向灰色去饱和；标准分类色不变。可比热图统一数值范围，分类色序不直接充当数值梯度；热图四边轴框封闭，色条不能替代右轴框。派生暖色、实际渐变锚点及 JSON 见 [配色库](../ABsCol/README.md)。

## 绘制与交付

- 图元函数接收已有 `ax`、数据及参数，追加绘制，不创建/清空画布，不管理范围、刻度、布局或导出。同一 ax 可叠加多组数据及不同图型；全局样式统一管理，每类图单独配置，对外接口集中。
- 调用方统一设定范围、刻度、图例和布局。范围覆盖全部观测与不确定性；连续轴通常用 3–4 个等间距主刻度封住两端，分类轴保留所需标签。真实数据不为美观删减，说明样本量及误差定义；示例标明模拟数据。
- 最终渲染后记录目标/实际绘图区、内容边界、真实间隙、编号锚点及总图幅；核查固定尺寸、同行等距、有效对齐、碰撞和裁切。可比边界及编号对齐容差 **1.5 pt**；必要例外说明原因，未执行的检查不声称通过。
- 仅导出 PDF 到运行代码旁的 `Figure/`，保留实际尺寸和可编辑文字。源数据与运行记录可放 `Log/`；分享时排除个人路径、私人数据、日志、缓存和过程测试文件。
