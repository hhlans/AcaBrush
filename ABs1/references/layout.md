# 测量布局接口

规范以 [SKILL.md](../SKILL.md) 为准。代码仅供参考；求解依赖 SciPy，不依赖本机目录。

```python
from abs1.api import finalize_measured_layout

report = finalize_measured_layout(
    fig, axes,  # name -> 已有 Axes；数据已画好、文字已设定
    rows=[["a", "b", "c"], ["d", "e"]],
    attachments={"e": [colorbar_ax]},
    horizontal_gap=0.18, vertical_gap=0.20,
    gap_mode="minimum",  # 或 fixed：每处严格为指定间隙，无解即报错
)
```

- 默认按各行数据子图的顺序推导列；仅在数据子图数量相同的行之间建立内容左缘及编号锚点。数量不同的行独立紧凑排布，独立图例不计数且不参与列绑定。`columns` 可提供逻辑列映射，但仍受同数量行分组限制；`columns={}` 可关闭跨行内容列约束。`plot_columns` 的绘图区对齐组也按同数量行分组，两种边缘不混用；有效约束冲突报 `LayoutConflict`。
- 保留调用前的实际绘图区宽高，首次调用后缓存目标，重复调用不累计缩放。设置新尺寸时由调用方重新创建/明确调整目标。
- 每行一个等距变量，共同求解所有相邻关系与列锚点；先最小化间隙，再最小化内容宽度。`max_horizontal_gap` 可限定可接受的最大间隙，超过则报冲突。
- `attachments` 接收独立创建的色条轴等，测量完整文字范围，保留相对父图的物理位置与尺寸。不要先用分割器挤小父图；接口不替调用方重设色条设计。
- 独立图例也应作为一个面板：`axes` 加入其容器，`rows` 加入名称，并用 `legend_panels={"legend": legend_artist}` 声明。只测量可见图例，不把透明容器当内容，不给图例编号。
- 编号使用求解得到的本行内容左缘，仅同数量行建立共用列锚点，不在后面逐个偏移；同行共用高于整行内容的基线。轴内容用于水平间隙，包含编号的完整内容用于行间间隙，两者分别记录。
- 返回报告包含目标绘图区、真实内容边界、含编号边界、各处实际间隙、总图幅和约束信息。总图幅直接取内容、真实间隙和指定外边距之和，不取整、不增加补齐留白。导出前仍检查最终 PDF 的文字、数据碰撞与对齐。

旧 `finalize_layout` 仍是旧占格实现；不要把其结果称为本接口的联合测量排版。过程验证脚本已移除；通用实现保留在 `abs1/measured_layout.py`，由 `abs1.api` 统一导出。
